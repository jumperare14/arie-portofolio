DEPLOY KE GITHUB PAGES
1. Masuk ke GitHub dan buat repository baru. Untuk URL username.github.io, nama repository harus persis username.github.io. Alternatif: repository biasa, misalnya arie-portfolio.
2. Upload ISI folder ini (index.html harus berada di root repository, bukan di dalam folder tambahan).
3. Buka repository → Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu deployment. URL biasanya https://USERNAME.github.io untuk repository khusus, atau https://USERNAME.github.io/NAMA-REPOSITORY/ untuk repository biasa.
7. Periksa alamat yang tampil di Settings → Pages.

Periksa email, nomor WhatsApp, pendidikan, dan rentang pengalaman sebelum publikasi. Studi kasus adalah ringkasan kategori pekerjaan, bukan metrik hasil terverifikasi. Jangan unggah informasi internal perusahaan.
